Condor PS3 Grid

Distributed batch computing with Condor job scheduling across PS3 resources

The Condor PS3 Grid combines the HTCondor distributed computing framework with PlayStation 3 resources to enable large-scale batch processing of gravitational physics simulations. This system allows researchers to submit parameter studies and ensemble computations that are automatically distributed across available resources.

HTCondor Distributed Computing Framework

GK

HTCondor (formerly Condor) is a specialized workload management system designed for high-throughput computing. It automatically manages job scheduling, resource allocation, and fault tolerance across a pool of computing resources.

We integrated HTCondor with our PS3 cluster to enable efficient batch processing of thousands of independent gravitational wave simulations, each exploring different parameter combinations.

Job Specification & Submission

GK, SF

We developed wrapper scripts and tools that translate physics simulation requests into HTCondor job specifications. Researchers can submit complex parameter sweeps and receive aggregated results without managing individual jobs.

The system handles automatic retries on failure, checkpointing for long-running jobs, and result aggregation from distributed workers.

Resource Allocation & Load Balancing

GK

HTCondor's intelligent scheduling algorithm automatically balances load across available PS3 resources, maximizing cluster utilization while respecting user priorities and resource constraints.

The system dynamically responds to resource availability, preempting lower-priority jobs when higher-priority work arrives and seamlessly resuming them when resources become available.

Parameter Space Exploration

SF, GK

The Condor PS3 Grid excels at parameter space exploration. A researcher can specify a multi-dimensional parameter grid, and the system automatically generates thousands of individual jobs, submits them to the cluster, and coordinates their execution across available resources.

This enables comprehensive surveys of black hole properties, orbital configurations, and numerical schemes that would be impractical with smaller resources.

Fault Tolerance & Checkpointing

GK

Long-running simulations require robustness against node failures. We implemented periodic checkpointing to save simulation state, allowing jobs to resume from the last checkpoint rather than restarting from the beginning.

This dramatically improves the practical utility of the system for long-running physics simulations.

Integration with Analysis Pipelines

GK, SF

The Condor PS3 Grid integrates seamlessly with analysis pipelines. Output from thousands of simulations can be automatically processed, analyzed, and visualized to extract physical insights or validate theoretical predictions.
