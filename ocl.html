OpenCL & GPU Computing

Portable high-performance computing with OpenCL across diverse hardware accelerators

Our group is actively engaged in research and development of GPU-accelerated computational methods using OpenCL and CUDA. This work enables high-performance simulations of gravitational physics on modern computing hardware, with a focus on portability and performance optimization.

OpenCL Framework for Scientific Computing

GK

OpenCL provides a portable abstraction for heterogeneous computing across CPUs, GPUs, and specialized accelerators. We develop OpenCL kernels for the bottleneck operations in gravitational wave simulations, particularly time-stepping and solution evaluation.

The portability of OpenCL allows our codes to run efficiently on NVIDIA GPUs, AMD GPUs, Intel processors, and even mobile accelerators, minimizing platform-specific optimization requirements.

GPU-Accelerated Teukolsky Solvers

GK, SF

We have developed GPU-accelerated implementations of our time-domain Teukolsky equation solvers using OpenCL and CUDA. These implementations achieve 20-50× speedups compared to optimized CPU versions, depending on GPU architecture.

The GPU codes handle the same computational grid and use the same numerical schemes as CPU versions, ensuring numerical consistency while providing dramatic performance gains.

Memory Optimization & Data Movement

GK, SF

GPU performance depends critically on efficient data movement between host and device memory. We develop strategies for minimizing data transfers, leveraging GPU device memory for intermediate results, and optimizing memory layout for coalesced access patterns.

Advanced techniques include pinned memory, asynchronous transfers, and overlapping computation with communication to hide communication latency.

Heterogeneous Computing Frameworks

GK

We develop software frameworks that automatically manage computation distribution across heterogeneous platforms — simultaneously utilizing CPUs and multiple GPUs. This allows efficient use of diverse hardware configurations without user intervention.

Performance Benchmarking & Profiling

GK, SF

Rigorous performance analysis is essential to validate optimization efforts and identify bottlenecks. We employ profiling tools like NVIDIA Nsight and AMD uProf to analyze GPU kernels and optimize execution.

Benchmarking against CPU and other GPU implementations validates our performance claims and guides further optimization efforts.

Machine Learning on GPUs

SF, GK

Modern machine learning frameworks (PyTorch, TensorFlow) run efficiently on GPUs. We leverage these tools for surrogate model training and inference, achieving rapid waveform predictions needed for parameter estimation in gravitational wave astronomy.
