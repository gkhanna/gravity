# gravity

Modern static restoration of the old Gravity Research Consortium website from `/home/ubuntu/.openclaw/workspace/OldWeb`.

Live site target: `https://gkhanna.github.io/gravity/`

The site preserves the original research content in a modern interface and keeps selected original static pages, media, PDFs, SHOC benchmark text files, and image galleries reachable. Dynamic/server-side dumps from the old archive are intentionally excluded from the public site.
