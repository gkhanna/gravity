## 🚀 How to Use / Next Steps

### View the Site
1. Open https://gkhanna.github.io/gravity/ in your browser
2. (May take 1-2 minutes for cache to refresh from previous version)
3. Test on mobile devices to verify responsive design

### Make Changes
1. Edit files locally in `/home/ubuntu/.openclaw/projects/active/gravity-website/`
2. Commit: `git add -A && git commit -m "Description"`
3. Push: `git push`
4. Changes automatically deploy to GitHub Pages

### Customize Design
- **Colors:** Modify CSS variables in `styles.css` (lines 4-18)
- **Typography:** Font family adjustable in `styles.css`
- **Spacing:** Adjust padding/margins in component classes
- **Content:** Edit individual `.html` pages

### Add New Pages
1. Copy template from `bh.html`
2. Update title, header nav links, page header
3. Add research projects to `.research-projects` div
4. Update sidebar with relevant links
5. Commit and push

## 📝 Design Philosophy

**Goal:** Modernize while respecting heritage

This redesign balances two objectives:
1. **Contemporary Design:** Clean, modern aesthetic that looks professional and current in 2026
2. **Respect for History:** Color palette and structure echo the original gravity.phy.umassd.edu aesthetic

The result is a website that feels current and professional while maintaining connection to the research group's history and the original blue-on-black design ethos.
